# QWQ 动态记忆 V5.3.0 完整代码包

## 升级方式
1. 在旧版本中导出一次完整记忆库备份。
2. 解压本完整代码包，覆盖旧程序目录中的同名文件。
3. 不要导入任何空表模板，也不要清除浏览器或应用数据。
4. 完全关闭应用后重新打开；网页环境建议强制刷新一次。

## 数据说明
- 本版继续使用 `STORE_VERSION=3`，不会因升级主动重建9张表。
- 程序包不包含个人记忆数据；已有数据继续由原域名、端口或应用环境的本地存储读取。
- 本包不再附带静态空表模板，界面只保留“导出空模板”，用于备份表结构。

## V5.3重点
- Android及移动端弹窗使用可视视口高度，软键盘弹起时保存区保持可达。
- 长文本编辑限制自动增高上限，超出后在文本框内部滚动。
- 大量记录按页渲染，默认每页100条，可在记忆设置中调整为20—500条。
- Rows表头和操作列固定，横向滑动时仍可识别字段并编辑记录。
- 拖动列宽后同步更新整张表宽度并保存。
- 覆盖全部导入前自动下载当前记忆库备份；保存失败自动恢复导入前内存状态。
- 用空表结构覆盖同名表但不勾选记录时，保留原有记录，不再意外清空。
- 删除表格和有数据的自定义字段时显示影响范围。

完整说明见 `docs/UPGRADE_V5_3.md`。
