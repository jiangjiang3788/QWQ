# QWQ 动态记忆 V5.2.0 完整代码包

## 升级方式
1. 在旧版本中导出完整记忆库备份。
2. 解压本完整代码包，覆盖旧程序目录中的同名文件。
3. 不要重新导入 V5.1 空表模板。
4. 完全关闭应用后重新打开，或清除网页缓存后刷新。

## 数据说明
- 本版继续使用 `STORE_VERSION=3`。
- 程序包不包含你的个人表格数据；已有数据仍由原安装环境的本地存储保存。
- 覆盖代码不会执行空表重建，但更换域名、端口、应用包名或清除浏览器数据会导致访问不到原本地存储。

## V5.2流程
打开“近期事项”或“想法与启示”，选择短期记录，生成并编辑中期总结草稿。总结保存成功后，来源记录才会被标记为已压缩并停止发送；确认无遗漏后可手动删除来源记录。
