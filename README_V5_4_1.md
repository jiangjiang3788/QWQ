# QWQ 动态记忆 V5.4.1 完整代码包

## 版本定位
V5.4.1 是主私聊上下文统一编译版。V5.4.0 的来源注册从影子对账进入真实请求阶段：最终 request body 在发送前统一经过 `OVOContextCompiler`，Proment 中的结构化记忆、聊天历史和状态开关开始真实控制模型请求。

## 原地升级
1. 在旧版中先导出一次完整记忆库备份。
2. 解压本包并覆盖原程序目录中的同名文件。
3. 不要导入空表模板，不要清除浏览器或应用数据。
4. 完全关闭后重新打开；网页环境建议强制刷新。

## 数据兼容
- `STORE_VERSION=3` 保持不变。
- 不重建9张表，不清空已有表格和记录。
- 已停用业务仍采用“旧数据保留但不读取、不写入、不发送”的策略。

## 本版核心变更
- 新增 `js/core/context_compiler.js`，成为主私聊最终上下文的统一编译入口。
- 结构化记忆开关和字符预算真实作用于最终请求。
- 最近聊天开关和条数真实作用于最终请求；关闭历史时只保留本轮用户输入及必要控制消息。
- 状态注入开关真实作用于最终请求。
- 最终 Manifest 改为 `compiled` 模式，对 system、历史、本轮输入、控制消息、Tools 和请求参数统一登记。
- 世界书命中、关键词、预算和诊断逻辑从 `chat_ai.js` 移入 `WorldBookContextProvider`。
- 核心档案与当前状态改为按分类展开的纵向列表；分类标题与记录标题同为16px。
- Rows 表头继续隐藏 aiHint，但配置数据仍保留供AI写入使用。

## 当前边界
- 本版统一的是主私聊最终请求；日记、通话、图片识别、小剧场等其他AI任务将在 V5.4.2 迁入统一 Gateway。
- 世界书和结构化记忆的开关、预算已真实生效；来源优先级目前主要用于注册清单和诊断，旧模板中的相对位置暂时保留，避免改变现有角色回复风格。
