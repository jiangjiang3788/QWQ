# QWQ 动态记忆 V5.4.3 完整代码包

## 版本定位
V5.4.3 是“Proment、悬浮球与操作记录收敛版”。V5.4.2 已将主要 AI 任务迁入统一请求网关；本版让 Proment、真实 Context Manifest、操作运行时和悬浮球读取同一份来源数据，删除对单人使用没有必要的重复模拟与重型历史记录。

## 原地升级
1. 先导出一次完整记忆库备份。
2. 解压本包并覆盖原程序目录中的同名文件。
3. 不要导入空表模板，不要清除浏览器或应用数据。
4. 完全关闭应用后重新打开；网页环境建议强制刷新。

## 数据兼容
- `STORE_VERSION=3` 不变。
- 不重建9张表，不清空已有表格和记录。
- V5.4.1b 的 KV 列表、字号、右侧编辑/删除和分割线布局继续保留。
- 聊天记忆状态栏继续支持点击、Enter和空格直达“当前状态”表。

## Proment 收敛
- 删除可见的“设计预览、设计/真实对照、世界书命中诊断、AI请求诊断”等重复入口。
- Proment只保留上下文开关与预算、来源注册表、最近真实请求和系统提示词模板。
- 来源注册表直接读取 `OVOContextSourceRegistry`，显示来源ID、领域、层级、任务范围、开关和预算状态。
- 最近真实请求直接读取操作记录中的 `Context Manifest`，显示实际发送、未发送、字符数和原因。
- 实际请求正文预览只在 Proment 展示；悬浮球不再保存和展开完整 Prompt。
- 世界书、结构化记忆、最近聊天和当前状态的设置继续真实控制最终请求。

## 悬浮球收敛
继续保留：
- 当前任务、执行阶段、耗时和取消；
- 模型列表与切换；
- Git上传与恢复；
- 控制台和日志复制；
- 操作历史、子操作、数据变化和错误；
- 来源摘要和来源跳转。

继续不提供：
- Proment入口；
- 记忆Payload核验；
- 能力覆盖率；
- 报告导出。

来源展示改为读取真实 `Context Manifest`。悬浮球只显示标题、纳入状态、字符数和原因；完整请求统一在Proment查看。

## 操作记录收敛
- 操作历史从最多100条收敛到最近20条。
- 详细记录从8条收敛到5条。
- 会话存储预算从约90万字符降到26万字符。
- 请求正文预览上限从12万字符降到1.6万字符。
- 单条数据变化正文上限从4000字符降到1200字符。
- 有 `Context Manifest` 的请求不再重复运行 `PromptTrace` 反向猜测。
- 每次请求生成统一 `sourceSummary`：来源总数、实际发送数、排除数、字符数和覆盖结果。

## 当前边界
旧的Proment模拟函数和操作报告底层兼容函数暂时保留但不再进入产品界面，计划在V5.4.4统一删除，避免本版同时迁移与大规模删除造成回归。

## 下一阶段
V5.4.4 将清理旧Prompt拼装、PromptTrace反向猜测主逻辑、各模块遗留兼容分支和不再使用的报告实现，并把旧数据兼容集中到独立适配器。
