# QWQ 动态记忆 V5.4.2 完整代码包

## 版本定位
V5.4.2 是“其他 AI 任务统一迁移版”。V5.4.1 已统一主私聊上下文编译；本版新增 `OVOAIRequestGateway`，把保留的其他模型任务收敛到同一个应用层入口，并为每次真实请求生成任务级 Context Manifest。

## 原地升级
1. 先导出一次完整记忆库备份。
2. 解压本包并覆盖原程序目录中的同名文件。
3. 不要导入空表模板，不要清除浏览器或应用数据。
4. 完全关闭应用后重新打开；网页环境建议强制刷新。

## 数据兼容
- `STORE_VERSION=3` 不变。
- 不重建9张表，不清空已有表格和记录。
- V5.4.1b 的列表字号、右侧编辑/删除和分割线布局全部保留。

## 本版完成
- 新增 `js/core/ai_request_gateway.js`，成为业务模块唯一的模型请求入口。
- 主聊天保留 V5.4.1 的正式 ContextCompiler 和 compiled Manifest。
- 日记生成、日记合并、小剧场、角色主动小剧场通过通用函数进入网关。
- 图片描述、头像识别、表情包识别直接迁入网关。
- 通话回复、通话总结、低电量互动、关系判断迁入网关。
- GPT 生图、NovelAI 生图和 Embedding 请求迁入网关。
- 新增 `buildTaskManifest()`，登记任务指令、任务输入、图片输入、日记/小剧场/通话来源、工具、参数和 Provider 包装。
- 业务文件不再直接调用 `OVOAIRequestRuntime.request()`，也不再保留模型请求的 `fetch` 回退。
- 修复 V5.4.1b 完整包中 `context_compiler.js` 未进入 `index.html` 加载链的问题。
- 聊天记忆状态栏可点击、Enter 或空格直达当前角色的“当前状态”表，并增加鼠标和焦点样式。

## 仍保留的边界
- 模型列表拉取、天气、Git、普通网络资源下载不是 Prompt/模型推理请求，不进入 Context Manifest。
- TTS 是语音服务链路，仍由现有 TTS 模块管理；它不参与聊天 Prompt 上下文编译。

## 下一阶段
V5.4.3 将收敛 Proment、悬浮球和操作记录：Proment 只保留来源注册、模板和真实请求；悬浮球继续保留现有运行/日志/模型/Git/数据变化功能，但不恢复已移除的 Proment、记忆 Payload 核验、能力覆盖率和报告导出。
