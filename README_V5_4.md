# QWQ 动态记忆 V5.4.0 完整代码包

## 版本定位
V5.4.0 是“架构收敛第一版”：先让明确不用的业务退出实际运行链路，再建立 AI 上下文统一注册中心的骨架和影子清单。本版尚未用新编译器替换全部旧 Prompt 拼装；主聊天统一编译属于 V5.4.1。

## 原地升级
1. 在旧版本中导出一次完整记忆库备份。
2. 解压本包，覆盖旧程序目录中的同名文件。
3. 不要导入空表模板，不要清除浏览器或应用数据。
4. 完全关闭应用后重新打开；网页环境建议强制刷新。

## 数据兼容
- 继续使用 `STORE_VERSION=3`。
- 不重建9张记忆表，不删除现有表格和记录。
- 已停用功能的旧数据保留在本地，便于回退，但不会继续写入或发送给 AI。

## 本版退出的业务
- 节点摘要及其输出协议；
- 亲属卡、消费记录的 AI 注入与模型指令解析；
- 偷看手机、冒充角色消息、手机控制、权限撤回、跨聊天控制历史；
- 大号/小号记忆互通；
- 双语格式、双语规则及双语 CoT 检查。

## AI 上下文注册骨架
新增 `OVOContextSourceRegistry`，登记角色、用户、世界书、结构化记忆、聊天历史、本轮输入、天气、提醒、收藏、输出协议、工具和请求参数等来源。主私聊请求会生成影子 Manifest，并随操作记录保存，用于后续迁移和对账。

影子模式只登记和诊断，不改变现有 Prompt 的正常业务效果；真实来源开关、预算和统一编译将在 V5.4.1 接管。

## 悬浮球收敛
从悬浮球移除：
- Proment入口；
- 记忆 Payload 核验；
- 能力覆盖率；
- 操作报告复制和下载、历史报告导出。

继续保留模型切换、Git上传/恢复、日志、操作历史、子操作、请求详情、Prompt来源与跳转、数据变化、错误和取消操作。

完整说明见 `docs/UPGRADE_V5_4.md`。
