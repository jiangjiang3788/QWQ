# V1.5.3 表设置弹窗重构

## 原因

旧版 `memory_simple_v1.css` 是按版本持续追加覆盖规则形成的。同一选择器出现多次：

- `.sm-modal`
- `.sm-modal-form`
- `.sm-modal-body`
- `.sm-modal-overlay`
- `.sm-form-grid`
- `.sm-form-section`

其中存在几组直接冲突：

1. 弹窗遮罩层使用 `touch-action:none`，会从祖先层阻止手机触摸滚动。
2. 弹窗正文同时使用 `height:100%`、`max-height:100%` 和 Flex 布局，未为标题、底部按钮正确让出空间。
3. 表设置卡片和网格使用 `overflow:hidden`，后续字段表格样式覆盖后，普通设置区域可能被压缩。
4. 桌面与手机规则多次重复定义高度和 overflow，修复一处会触发另一组旧规则。

## 新结构

弹窗现在只有一个纵向滚动容器：

```text
sm-modal
├── sm-modal-head（固定）
└── sm-modal-form
    ├── sm-modal-body（唯一纵向滚动区）
    └── sm-modal-foot（固定）
```

动态字段配置表只承担横向滚动，不再创建第二个纵向滚动区。

## 表设置布局

以下区域均使用统一卡片：

- 基本设置
- 用途与 AI 提取
- 动态字段
- 短期写入
- 分类与标签提示
- USER 状态栏
- 中期积累
- 分类和标签注入

卡片内容始终展开，不使用折叠和隐藏高度。

## 完整文本

弹窗内所有 `textarea` 在打开和输入时根据 `scrollHeight` 自动增高。正式数据没有截断，长文本由弹窗正文统一滚动。

## 手机端

- 弹窗使用 `100dvh` 全屏。
- 顶部标题和底部按钮保持可见。
- 中间内容可以触摸纵向滑动。
- 动态字段表可左右滑动。
- 安全区已加入顶部和底部间距。
