# V5.1.1 原地升级说明

## 不需要重新导入空表

本修复版继续使用 `STORE_VERSION = 3`。升级时只覆盖程序文件，不执行“覆盖全部表格”，不导入 `V5.1 空表模板`。已有表格、字段顺序、分类标签提示和记录继续保留。

建议使用补丁包覆盖原 V5.1 目录中的同名文件，并保持原来的访问地址/安装位置，避免浏览器把它识别为另一个站点。

## 本版修复

1. 空表没有可发送记录时，不再因为缺少 `structured_archive_memory` 阻断聊天。
2. `memory_ops` 即使闭合标签写成 `<\/memory_ops>`、缺少开始标签或JSON不完整，也会先从可见回复中清除。
3. 写入操作采用严格结构校验。
4. `add` 只负责创建完整新记录，`upsert` 只负责更新已存在记录。
5. 核心档案、中期总结、稳定长期记忆的聊天AI权限由执行器强制限制。
6. 当前状态不按固定天数自动失效；日常观察按日期识别同日记录。

## 覆盖文件

补丁包内文件应覆盖原目录同名文件。覆盖前可先复制整个旧目录作为程序备份；记忆数据仍建议在应用内导出一份完整记忆库备份。
