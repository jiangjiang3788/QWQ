# QWQ 动态记忆 V5.2 原地升级说明

## 数据安全
V5.2 继续使用 `STORE_VERSION=3`。覆盖程序文件不会重新载入空表，也不会清空现有表格和记录。界面已移除“重新载入空表”入口，避免误操作。升级前仍建议先导出完整记忆库备份。

## 完整升级流程
1. 在旧版中导出完整记忆库备份。
2. 解压 V5.2 完整代码包，覆盖旧程序目录中的同名文件。
3. 不要导入 V5.1 或 V5.2 空表模板。
4. 完全关闭应用后重新打开。

## V5.2 功能流程
### 短期到中期
1. 打开“近期事项”或“想法与启示”。
2. 点击“压缩所选短期记录”。
3. 选择来源记录并生成结构化草稿。
4. 用户检查和编辑草稿。
5. 保存中期总结成功后，来源记录才标记为已压缩。
6. 已压缩来源停止进入聊天上下文，但不会立即删除。
7. 用户确认无遗漏后，可批量删除已压缩来源。

### 中期到长期
1. 打开“事项总结”或“思想与成长总结”。
2. 点击“生成长期草稿”。
3. 选择中期总结。
4. 检查长期规律、适用条件和例外。
5. 用户点击确认后，才写入“稳定长期记忆”。

## 权限边界
聊天 AI 不能直接写核心档案、中期总结和稳定长期记忆。压缩流程只能写中期表；长期记录只能以用户手动确认的方式保存。

## 当前边界
本版的中期和长期草稿采用本地结构化整理并允许人工编辑，没有额外发起一次模型请求。这样可以减少耗时和接口成本，也避免总结失败时破坏来源记录。
