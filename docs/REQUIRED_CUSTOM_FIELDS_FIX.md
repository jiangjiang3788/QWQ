# 自定义字段必填修复

本补丁在记忆表格编辑器中增加了自定义字段“必填”开关，并让自动写入引擎真正执行该设置。

## 修改内容

- 自定义字段可逐项勾选“必填”。
- 保存表格后保留自定义字段的 `required` 值，不再统一重置为 `false`。
- 新增记忆时，缺少任一可见且设为必填的自定义字段会被拒绝写入。
- 分类、标题、内容仍保持基础必填规则。
- 表格提示中明确显示每个字段是必填还是选填。
- 自动记忆仅以本轮用户消息为证据，禁止把助手本轮自行生成的推断直接写入记忆。
- 同一信息默认只进入一张主表，减少跨表重复。
- 候选旧记录数量改为遵循“相关表每表最多记录”全局设置；日常观察最多取8条。

## 使用方式

打开记忆系统的表格设置，在“字段设置”中勾选自定义字段对应的“必填”，保存即可。该设置主要约束新增记录；更新旧记录时仍允许只提交本轮发生变化的字段。
