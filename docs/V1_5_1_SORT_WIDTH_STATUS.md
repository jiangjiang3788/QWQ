# V1.5.1 多维排序、字段宽度与USER状态栏

## Rows多维排序
- 点击Rows表顶部的“多维排序”。
- 可添加多个字段，每个字段选择升序或降序。
- 规则从上到下执行，第一项优先级最高。
- 可通过上下箭头调整排序优先级。
- 同一字段重复添加时，保存会仅保留优先级最高的一项。
- 排序规则保存在 `table.display.sortRules`，刷新和重新进入后仍然有效。

## 字段显示顺序
- 打开“表设置”，在动态字段表格的“顺序”列使用上移、下移按钮。
- 保存后的字段数组顺序同时决定：Rows列顺序、KV字段顺序、记录编辑表单顺序、USER状态值顺序。

## 字段宽度
- 表设置中可直接输入80–800px。
- Rows表头右边缘可拖动调整宽度，松开后立即保存。
- 字段宽度保存在字段定义的 `width` 中，不是临时UI状态。
- 内容单元格和表头使用同一个宽度，避免只改变表头。

## KV字段名
- 桌面端左侧字段名最大宽度160px。
- 手机端最大宽度140px。
- 右侧字段值占用剩余空间，长字段名自动换行。

## USER状态栏
- 只显示非空字段的值，不显示字段名，也不显示“USER状态”标题。
- 桌面端文字约15px，手机端约14px。
- 状态值的顺序跟随该KV表的字段显示顺序。
