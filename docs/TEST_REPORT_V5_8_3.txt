QWQ V5.8.3 测试报告

主题：角色收藏恢复为私人情感动作

检查结果：
1. 全部 JavaScript 文件通过 node --check 语法检查。
2. 23 个测试文件执行完成，22 个通过，1 个因缺少旧版外部迁移样本按原设计跳过，失败 0。
3. 收藏提示中不再存在“每轮最多一条”、当前轮限定或重要信息清单。
4. 当前请求中可见的历史用户消息与本轮用户消息都可获得内部 message_meta id。
5. 消息正文前不再插入醒目的 [id:...]。
6. 短句“嗯”可被角色收藏，存储层不按信息量裁决。
7. 空收藏寄语可以正常写入。
8. 两条不同消息即使正文相同，也可以分别收藏。
9. 同一条具体消息被同一角色重复收藏仍会被拒绝。
10. 同一模型回复中的多个收藏动作可逐条执行，不存在每轮配额截断。
11. 收藏标签由程序自动生成，不要求模型输出标签。
12. 用户手动收藏和旧收藏迁移流程保持正常。
13. 世界书、核心档案、分层记忆和悬浮球请求项目回归测试通过。

私人数据：未写入代码包、测试夹具或文档。
