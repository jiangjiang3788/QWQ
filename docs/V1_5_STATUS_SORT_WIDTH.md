# V1.5 状态、排序与列宽

## USER状态每轮检查
- 被设置为聊天USER状态栏来源的短期KV表，会在AI协议中标记 `mustUpdateEveryRound=true`。
- AI每轮都需要提交一次该表的 upsert。
- 字段值发生变化：写入正式表，并显示本轮绿点。
- 字段值没有变化：提示“本轮USER状态已检查：没有变化”，不显示绿点。
- 其他记忆仍然只在有新内容时写入。

## Rows多维排序
- 表格工具栏增加“多维排序”。
- 可添加多个字段，排序优先级从上到下。
- 每个字段可设置升序或降序。
- 规则保存在 `table.display.sortRules`，刷新后保留。

## 字段显示顺序
- 表设置的字段配置表增加上移、下移按钮。
- 字段数组顺序就是KV显示顺序、Rows列顺序和编辑表单顺序。

## 字段宽度
- 表设置可输入80–800px字段宽度。
- Rows表头右侧可直接拖动调整列宽。
- 宽度保存在字段定义的 `column.width`。

## KV与状态栏
- KV字段名区域最大宽度160px，内容区自动占用剩余空间。
- 手机端字段名区域最大140px。
- 聊天USER状态栏只显示字段值，不显示字段名或USER状态标题。
- 状态栏字号和胶囊内容字号已增大。
