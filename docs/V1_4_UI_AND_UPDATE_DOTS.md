# V1.4 绿点、手机滚动与表格编辑UI

## 绿点规则

绿点只对应当前聊天轮次。当前轮有正式写入时，相关表显示绿点；KV表在被更新的字段名旁显示；Rows表在被更新的具体内容单元格旁显示。下一轮没有记忆更新时，当前轮报告会替换上一轮报告，所有绿点立即消失。

历史记录中的 lastChange 与 fieldChanges 仍用于数据维护，但不再直接决定界面绿点。界面同时要求写入标记的 roundId 与当前轮 roundId 一致。

## Rows显示

Rows字段标题不显示绿点。只有被本轮写入的记录内容单元格显示绿点。已移除“记忆标识”列以及“AI判断·更新”等重复文字标记。

## 手机端滚动

记忆页面只保留最外层 content 作为纵向滚动容器。手机端 sidebar 和 main 不再建立独立纵向滚动区域；Rows表仅在需要时横向滚动，从而避免手指滑动被嵌套 overflow 截获。

## 表格编辑UI

动态字段设置改成表格结构：字段名、类型、选项、隐藏、aiHint、操作。桌面端完整展示；手机端弹窗全屏，字段配置区可横向滑动，底部保存栏固定。
