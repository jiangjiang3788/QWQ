# QWQ 动态记忆 V5.3 原地升级说明

## 数据安全
V5.3继续使用 `STORE_VERSION=3`。覆盖代码不会重新载入空表，也不会主动清空已有表格或记录。升级前仍建议先在当前版本中点击“导出全部”。

不要更换域名、端口、应用包名，也不要清除站点数据，否则原本地存储可能无法被新代码访问。

## 升级步骤
1. 导出当前完整记忆库。
2. 解压V5.3完整包，覆盖旧目录中的同名文件。
3. 完全关闭应用后重新打开；网页端可执行强制刷新。
4. 打开记忆页面，确认原表格和原记录仍存在。
5. 用一轮普通聊天检查自动写入、绿点和状态栏。

## 稳定性改动
### 移动端和软键盘
- 弹窗高度跟随 `visualViewport`，不再只依赖固定的 `100vh`。
- 输入框获得焦点后自动滚动到可视区域中部。
- 弹窗打开时锁定背景滚动。
- 保存与取消区固定在弹窗底部，并考虑底部安全区。

### 长文本和横向表格
- 长文本仍显示完整内容，但自动增高有上限；超过上限后文本框内部滚动。
- Rows视图保留横向滑动，并固定表头和右侧操作列。
- 列宽拖动结束后立即持久化，整张表宽度同步更新。

### 大量记录
- 默认每页100条，仅渲染当前页，降低一次渲染数百或上千条记录时的卡顿。
- 每页数量可以在“记忆设置”中设为20—500条。
- 搜索、分类和标签筛选后自动回到第一页。

### 导入导出
- 完整导出增加应用版本和导出时间，但仍兼容V5导入识别。
- “覆盖全部表格”必须勾选明确确认。
- 覆盖全部前自动下载导入前备份。
- 保存导入结果失败时，恢复导入前内存状态并显示失败阶段。
- 同名表选择“覆盖表结构”且未勾选“导入文件中的记录”时，保留现有记录并按新表结构标准化。

### 删除保护
- 删除表格前显示记录数量，以及哪些表把它作为压缩来源。
- 删除已有数据的自定义字段时显示受影响记录数量。
- 公共字段仍不能删除。

## 保持不变
- 9张表底层结构和 `STORE_VERSION=3` 不变。
- 完整轮次自动写入、`memory_ops`清理和权限边界不变。
- 短期压缩、中期总结和长期草稿人工确认流程不变。
- 不增加旧V4数据迁移，也不恢复“重新载入空表”功能。
