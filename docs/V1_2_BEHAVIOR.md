# V1.2 记忆写入、标识与上下文规则

## 写入

短期AI写入只校验：目标表存在、表为已启用短期表、字段合法、信息来源合法。分类和标签没有命中提示词时也不会拒绝写入。

表设置中的“分类提示”和“标签提示”只是提供给AI选择表和填写元数据，不是权限规则。

## extractPrompt 与 aiHint

- `extractPrompt`：整张表的提取规则，说明什么情况下写、如何总结、什么内容不写。
- `aiHint`：单个字段的填写规则，说明字段含义、判断尺度、格式要求。

两者保存在动态表定义中，并随每轮短期表结构一起发送给AI。

## 持久更新标识

每次写入都会保存：

- 记录级 `lastChange`：新增/更新、信息来源、时间。
- 字段级 `fieldChanges`：主要用于KV表，分别记录每个字段最后一次新增或更新。

Rows表显示记录级标识；KV表显示字段级标识。旧数据会根据创建时间、更新时间及原信息来源补一个可见标识。

## 上下文引用

只读取聊天历史中的最后1条消息作为匹配文本。

然后：

1. 跳过带“禁止注入”标签的记录；
2. 应用表自身的限定分类、必须含标签、排除标签；
3. “始终注入”标签直接进入；
4. 其他记录需要分类或至少一个标签出现在最后1条消息中；
5. 按始终注入、分类命中、标签命中及更新时间排序，取全局最大记录数。

分类和标签只决定引用，不决定能否写入。
