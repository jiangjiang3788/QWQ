# QWQ 动态记忆 V5.4.4 完整代码包

## 版本定位
V5.4.4 是既定五阶段计划的最后一版：遗留代码清理与稳定收尾。它修复聊天顶部 `memory-live-state-bar` 点击无效的问题，并移除已经被 Context Manifest、统一 Gateway 和 Proment 治理页替代的旧 Prompt 反向猜测与模拟诊断链路。

## 状态栏点击 Bug 根因
旧代码在 `openMemoryTableForCharacter()` 中调用了不存在的 `window.showScreen()`；本项目实际导航函数是 `window.switchScreen()`。因此点击事件确实触发了，但没有完成页面切换。本版同时把状态栏改为语义化 button，并增加直接角色/表格定位和可靠的兜底跳转。

## 本版完成
- 聊天状态栏点击、Enter、空格均可直达当前角色的“当前状态”表。
- Proment 页面只保留真实来源注册表、真实请求、实际预算开关和系统提示词模板。
- 删除设计预览、设计/真实对照、世界书独立诊断、AI 请求重复诊断等旧 UI。
- 移除运行时 PromptTrace 反向推断；新请求只认 Context Manifest。
- 旧操作记录中已有 PromptTrace 仍可只读显示，不再生成新数据。
- 世界书诊断改为领域模块内存态，不再写入 sessionStorage。
- 通话任务改用正式任务名 `call.reply` 与 `call.summary`。
- 修正记忆模块内部错误使用 `showScreen` 的导航调用。

## 原地升级
1. 先导出一次完整记忆库备份。
2. 解压本包并覆盖原目录同名文件。
3. 不要导入空表模板，不要清除浏览器或应用数据。
4. 完全关闭应用后重新打开；网页环境建议强制刷新。

## 数据兼容
继续使用 `STORE_VERSION=3`。不会重建九张表，不会清空已有记录，也不会恢复已删除的节点摘要、双语、小号互通和手机控制业务。
